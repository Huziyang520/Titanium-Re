# Titanium Lite

Titanium Lite is the subset of [Titanium](https://github.com/InnovativeOnlineIndustries/Titanium) that Functional Storage actually uses. It keeps mod id `titanium` and the original LGPL-3.0 licence, and it is **bundled inside the Functional Storage jar** — it is not installed or distributed on its own.

钛 Lite 是 [Titanium](https://github.com/InnovativeOnlineIndustries/Titanium) 中功能性存储实际用到的子集。保留原 mod id `titanium` 与 LGPL-3.0 协议；以 **jar-in-jar 内嵌在功能性存储的 jar 里**，不单独安装、不单独发布。

## Branches
