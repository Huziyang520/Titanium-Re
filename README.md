# Titanium Lite

Titanium Lite is the subset of [Titanium](https://github.com/InnovativeOnlineIndustries/Titanium) that Functional Storage uses. Mod id stays `titanium`; the build is bundled inside the Functional Storage jar and is not distributed or installed on its own.

钛 Lite 是 [Titanium](https://github.com/InnovativeOnlineIndustries/Titanium) 中功能性存储实际用到的子集。mod id 保持 `titanium`；产物以 jar-in-jar 内嵌在功能性存储的 jar 里，不单独分发、不单独安装。

## Branches

| Branch | Minecraft | Loaders | Mod version |
|---|---|---|---|
| `26.3` | 26.3 | NeoForge, Fabric | `4.26-lite` |
| `26.1-26.2` | 26.1 – 26.2 | NeoForge, Fabric | `4.26-lite` |

Each branch is a self-contained Gradle project; the branch name is also the jar's Minecraft label.

This repository is the source of the bundled copy; it ships no standalone release.
